# 七日城：契约者 — 龙临前夜

黑暗奇幻 · 类 DND · 文字驱动 RPG（Web MVP V0.1）

> 帝国边境城市阿斯特拉，一头古龙将在两天后抵达。所有人认为它来毁灭城市——而你，一名罕见的「契约者」，将在 48 小时内调查出真相：这座城市的魔法能源，来自一枚被夺走的龙卵。

## 运行方法

```bash
npm install
npm run dev
```

打开终端输出的本地地址（默认 http://localhost:5173）即可游玩。

生产构建与测试：

```bash
npm run build     # 类型检查 + 产物构建到 dist/
npm run test      # Vitest 单元测试 + 通关模拟
```

## 技术栈

- React 19 + TypeScript + Vite
- Zustand（游戏状态，单 store）
- localStorage（自动存档，单槽位）
- 原生 CSS（黑暗奇幻 / 羊皮纸 / 深色背景 / 金色强调）
- Vitest（骰子、条件、效果、场景完整性、通关路线模拟）

无后端、无数据库、无登录、无大型依赖。

## 玩法

- **48 小时时间线**：DAY 1 / DAY 2 各四个时段，最终进入龙临事件，约 45–90 分钟。
- **六属性**：暴力 / 身手 / 洞察 / 学识 / 手腕 / 意志（0–4）。
- **检定**：2D6 + 属性 + 修正。≤5 失败（仍推进剧情）、6–8 成功有代价、9–11 成功、12+ 完美。
- **三名契约伙伴**：塞蕾娜（骑士·守护）、莉娅（盗贼·黑猫重掷）、米蕾娜（魔女·禁忌交换，腐化 +10）。
- **关系系统**：信任 / 亲密（0–100），关系阶段 陌生→熟悉→盟友→契约伙伴→羁绊；支持正负变化与伙伴拒绝。
- **契约系统**：信任 ≥ 60 且完成个人事件后可提出契约，伙伴可能接受或拒绝。
- **队伍**：最多携带 2 名伙伴，营地处可调整；伙伴在场会解锁专属选项。
- **秘密系统**：8 个可调查秘密，解锁特殊对话与隐藏结局。
- **四个主结局 + 一个隐藏结局**：龙归故乡 / 屠龙英雄 / 魔法革命 / 龙之契约（隐藏）。
- **失败不阻塞**：检定失败只会改变解决问题的方式。

## 主要目录

```
src/
  components/    UI（开始界面、游戏外壳、剧情、选项、侧栏、骰子、结局）
  engine/        骰子、条件、效果、场景引擎
  store/         Zustand 游戏状态与存档
  data/
    companions.ts  伙伴设定
    secrets.ts     秘密文案
    time.ts        时间轴
    scenes/        全部剧情场景（数据驱动，按地点分文件）
  types/         类型定义
  styles/        全局样式
```

剧情完全数据驱动（`Scene / Choice / Condition / Effect`），加剧情只需在 `data/scenes/` 添加场景文件。

## 已实现的玩法实例

- 洞察检定识破 NPC 谎言
- 检定失败但剧情继续（警戒 +1 等代价路径）
- 莉娅在场时的潜入专属选项
- 塞蕾娜信任足够时触发特殊对话
- 米蕾娜「禁忌交换」：腐化 +10 换成功
- 获得秘密后出现 🔎 特殊选项
- 伙伴因价值观选择增减信任/亲密
- 米蕾娜可以拒绝契约（信任不足或未完成个人事件时）
- 高关系伙伴在最终事件提供额外解法（龙之契约路线）
- 结局随秘密、关系与决定变化

## 测试路线（已自动化验证）

- **Route A** 偏塞蕾娜 → 归还龙卵
- **Route C** 偏米蕾娜 → 龙之契约（隐藏结局）
- 全场景无死路检查、nextScene 引用校验、Scene ID 唯一性

## 已知限制（MVP V0.1）

- 未做完整七日，仅「龙临前夜：48 小时」
- 伙伴个人事件每名 1 章（未做三章）
- 无装备栏、无商店、无独立战斗界面（战斗即场景选择 + 检定）
- 单存档槽，无手动多档
- 无图片素材，头像为字符圆形占位
- 契约事件需在营地夜晚触发（信任 ≥ 60 + 个人事件完成）
