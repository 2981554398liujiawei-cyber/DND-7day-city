# 七日城：契约者

龙临前夜 · 48 小时

**公开试玩**：https://2981554398liujiawei-cyber.github.io/DND-7day-city/

**当前**：V0.4 Release Candidate

黑暗奇幻 · 类 DND · 文字驱动 RPG。

- **游戏类型**：剧情驱动的单机文字 RPG（浏览器，无需安装）
- **单局预计时长**：45–90 分钟（48 小时完整篇章）
- **3 个出身**：流浪佣兵 / 禁术学者 / 街头骗徒（各有独特能力）
- **3 名可契约伙伴**：塞蕾娜（守护）、莉娅（黑猫重掷）、米蕾娜（禁忌交换）
- **2D6 检定规则**：≤5 失败 / 6–8 成功但有代价 / 9–11 成功 / 12+ 完美成功
- **本地自动存档**：单槽位，刷新页面可继续
- **当前为 48 小时完整篇章**：DAY1 + DAY2 + 龙临 Finale（6 种结局路线）

## 开发命令

```bash
npm install
npm run dev
npm run test
npm run lint
npm run build
```

无后端、无数据库、无登录；剧情完全数据驱动（`src/data/scenes/`），技术栈 React + TypeScript + Vite + Zustand + 原生 CSS。
